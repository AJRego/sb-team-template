The steps we follow to ship a Driftwood release, with who owns each.

* [ ] @mateo freeze `main` on Monday
* [ ] @pete run the full import test suite against the sample libraries
* [ ] @mateo tag `vX.Y.Z` and let CI build installers
* [ ] @jo update the public docs (the `docs/` space publishes itself)
* [ ] @sam announce in the newsletter
